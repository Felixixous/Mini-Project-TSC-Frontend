# Mini Project TSC - Frontend

Website statis biografi musisi Baskara Putra, dibuat dengan HTML dan CSS murni tanpa JavaScript.

🔗 **Live:** https://felixixous.github.io/Mini-Project-TSC-Frontend/

## Navigasi
- Home
- Profil
- Achievement
- Discography
- Similar Artist
- Fan Message

## Teknologi
- HTML5
- CSS3

## Yang dipelajari
- Struktur HTML semantik
- Layout dan styling dengan CSS Penggunaan Position dan Display Flex
